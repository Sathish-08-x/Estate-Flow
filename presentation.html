The Challenge

Problem Statement & Motivation

Why Property Agents Need EstateFlow

Property agents receive dozens of client inquiries daily from buyers and sellers across different channels. Without a centralized system:

⚠️ Missed Follow-ups

Agents lose track of client callback dates and site visit commitments.

📉 Lost Sales Pipeline

Inquiries get forgotten between initial contact and deal closure.

🔍 Search Inefficiency

No quick way to find matching budgets and property types.

📊 Lack of Visibility

Absence of real-time metrics on deals in progress.

Speaker: Sathish Gudipudi (12613921)
"Our problem statement addresses how property brokers lose track of leads and follow-up history. EstateFlow provides a clean, responsive single-page web solution."
Features

Key Features & Architecture

Full Rubric Implementation

1. Dynamic Lead Form

Captures client details, buyer/seller role, property type, budget, and priority.

2. Live Search Engine

Real-time filtering of all leads without page reloads.

3. 4-Stage Sales Pipeline

Visual board tracking: New Inquiry → Contacted → Site Visit → Closed Won.

4. Follow-up Schedule

Action-item calendar for scheduled calls, visits, and negotiations.
