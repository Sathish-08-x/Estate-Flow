## Project Overview
A web-based Lead Management and Sales Pipeline application built for property agents to organize buyer and seller inquiries, track follow-up schedules, and monitor sales progression.

## Problem Statement
Property agents receive enquiries from multiple buyers and sellers but can lose track of follow-ups, requirements, and communication history.

## Project Objective
Create a lead-management system that organizes property enquiries and sales progress.

---

## Core Functional Requirements

1. **Lead Profiles:**
   - Captures client name, role (Buyer vs. Seller), budget, and contact details.
2. **Property Interest:**
   - Categorizes buyer/seller preference (Apartment, House, Condo, Luxury Villa, Commercial Office).
3. **Lead Stages:**
   - Tracks inquiries across sales stages: *New*, *Contacted*, *Site Visit Scheduled*, *In Negotiation*, and *Closed Won*.
4. **Follow-Up Records:**
   - Scheduled action dates and upcoming tasks (Site visits, calls, price negotiations).
5. **Priority Badges:**
   - Color-coded visual priority tags: High, Medium, Low, V.High.
6. **Live Search Filter:**
   - Instant real-time filtering of inquiries by client name or property category.
7. **Visual Sales Pipeline:**
   - Multi-column pipeline tracking deals from initial inquiry to final closed stage.

## Technologies Used
- **HTML5:** Semantic page structure (`<header>`, `<aside>`, `<main>`, `<section>`, `<table>`, `<form>`).
- **CSS3:** Responsive outline design, CSS Flexbox and Grid layouts, clean border box model.
- **JavaScript (Vanilla ES6):** Real-time search filtering, dynamic lead submission to table, live lead counter.
